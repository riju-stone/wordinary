## APIs Used
- Generating Random Words - [Rando API](https://random-word-api.vercel.app/) & [Random Word API](https://random-word-api.herokuapp.com/home)
- Getting Word Data - [Free Dictionary API](https://api.dictionaryapi.dev/api/v2/entries/en/)
- Searching Similar Words - [DataMuse API](https://www.datamuse.com/api/)
